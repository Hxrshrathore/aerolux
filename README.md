## 🌟 Project Overview: What is AeroLux?

**AeroLux** is an ultra-modern, high-fidelity luxury private aviation digital platform prototype, conceptually centered around **Juhu Airport, Mumbai**.

Imagine you need to charter a private jet on short notice, experience a romantic sunset flight over the Arabian Sea, simulate an ICU aeromedical evacuation, or model a helicopter pilgrimage to Kedarnath. Traditionally, booking private aviation in India involves fragmented phone calls, opaque broker pricing, and zero digital transparency.

**AeroLux reimagines this entire experience.** It combines a fictional fleet of **30+ DGCA-standard aircraft** with an Apple-meets-Swiss editorial aesthetic. Visitors can explore real-time aircraft specifications, discover deeply discounted "empty leg" return flights, simulate emergency aeromedical requests, test interactive 3D cabin exploration, or connect directly with a flight dispatch simulation via instant WhatsApp concierge.

## 🚀 Key Features & Experiences

### 1. 🛩️ Private Jet Charters & Empty Leg Marketplace
* **Bespoke Charters:** On-demand private jet charter simulation across domestic corridors (Mumbai, Delhi, Goa, Bengaluru) and international hubs (Dubai, Maldives).
* **Empty Leg Deals:** Demonstrates how private jets flying empty ferry legs can be discovered and booked at up to **60%–70% off** standard charter rates.
* **Fleet Transparency:** Interactive display of cruise speeds (Mach 0.88), cruising altitudes (FL410 / 41,000 ft), nautical range, and VIP passenger configurations.

### 2. 🌅 Scenic Airplane Joyrides (Mumbai & Goa)
* **Scenic Sightseeing:** 30 to 60-minute scenic flight experiences departing from Juhu Aerodrome, capturing panoramic views over Marine Drive, the Bandra-Worli Sea Link, and coastal horizons.
* **Milestone Celebrations:** Celebration specials for anniversaries, proposals, and birthdays with high-altitude cake and champagne services.

### 3. 🕉️ Pilgrimage & Sacred Charters (Ek Dham Kedarnath)
* **Turnkey Spiritual Itinerary:** Complete 3-day spiritual pilgrimage experience modeled with luxury mountain stays at Phata, private helicopter shuttles landing 500m from Kedarnath Temple, and VIP Darshan pass assistance.

### 4. 🚑 Critical Care Aeromedical (Air Ambulance)
* **Life-Saving Medical Simulation:** Flying intensive care units equipped with ventilators, defibrillators, and aeromedical crew transfers.
* **Rapid Response Window:** 45-minute emergency launch timeline with bedside-to-bedside Pan-India patient logistics.

### 5. 💼 Turnkey B2B Airborne Solutions
* Corporate aviation solutions for aircraft owners: Aircraft Acquisitions, DGCA Compliance, Maintenance Management, Flight Operations, and Aviation Financing.

### 6. 🌐 Modern Digital UI/UX Innovations
* **Interactive Cabin & Fleet Hotspot Explorer:** Hotspot explorer allowing users to inspect full lie-flat beds, acoustic soundproofing, and handcrafted leather interiors, paired with interactive aviation trivia facts.
* **IndiGo-Grade Flight Search Engine:** Interactive one-way, round-trip, and multi-sector booking search with airport auto-suggestions, passenger selectors, and luggage calculators.
* **Fluid Glass 3D Navbar:** Custom WebGL-powered 3D refraction navbar that transitions gracefully as users scroll from the video hero into content curtains.
* **VIP Client Portal & Login Modal:** Seamless OTP and passwordless authentication with interactive card flip animations and instant itinerary previews.
* **Prototype Disclaimer System:** Floating reminder pill and global popup modal explicitly notifying visitors that this is a design prototype by **hxrshrathore**.

## 💻 Tech Stack (Explained for Everyone)

AeroLux was built using cutting-edge modern web technologies:

| Technology | What is it? | Why do we use it in AeroLux? |
|---|---|---|
| **Next.js 16 (App Router)** | The architectural foundation of the web app. | Delivers lightning-fast page loading, SEO flight route discoverability, and clean routing. |
| **React 19** | The interactive engine that controls how the UI responds. | Powers dynamic features like airport selectors, passenger counters, and modal popups with zero lag. |
| **Tailwind CSS v4** | The styling framework that creates our visual layout. | Delivers a clean, high-contrast, Swiss-minimalist aesthetic with luxury border radiuses and responsive layouts. |
| **Motion (Framer Motion v12)** | The physics-based animation tool. | Gives buttons, modals, and tab switches natural, springy, and smooth movements. |
| **GSAP 3 (GreenSock)** | High-performance animation engine. | Powers complex choreographed sequences like the cursor-expanding wave buttons and organic drifting clouds. |
| **Three.js & React Three Fiber** | 3D graphics in the web browser without any plugins. | Creates the realistic "Fluid Glass" navbar effect and renders interactive 3D aircraft components (`.glb` models). |
| **Lenis** | Smooth scrolling engine. | Makes page scrolling feel fluid and weightless, simulating the sensation of gliding through clouds. |
| **Lucide Icons** | Modern, minimalist vector iconography. | Clean, standardized aviation, emergency, and luxury icons throughout the user interface. |
| **Switzer & Geist Fonts** | Premium geometric sans-serif typography. | Delivers the refined, editorial luxury typography required for ultra-high-net-worth client experiences. |

## 🎨 The Process: How AeroLux Was Built

AeroLux was created through a multi-stage design and conversion optimization process:

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  Phase 1: Audit │ ──▶ │ Phase 2: Trust  │ ──▶ │ Phase 3: Motion │ ──▶ │ Phase 4: Speed  │
│  & Friction Cut │     │ & Authority     │     │ & 3D Delight    │     │ & Optimization  │
└─────────────────┘     └─────────────────┘     └─────────────────┘     └─────────────────┘
```

1. **Phase 1: Slashing Friction:** Re-engineered traditional bloated 10-field booking forms into clean 2-step progressive disclosures and instant WhatsApp inquiry touchpoints.
2. **Phase 2: Building Trust Before the Ask:** Integrated upfront DGCA safety benchmarks, verified fleet parameters, and authentic aviation photography.
3. **Phase 3: Sensory & Tactile Delight:** Created an atmospheric video hero, an interactive cabin hotspot explorer with aviation trivia, and interactive 3D fluid glass navbar refractions.
4. **Phase 4: Performance Engineering:** Added `IntersectionObserver` controllers to automatically pause background videos when scrolled out of view and lazy-loaded WebGL 3D canvases.

---

## 🧠 What We Learned

1. **Luxury Buyers Crave Instant Communication:** High-net-worth travelers prefer direct WhatsApp concierge access over filling lengthy web forms.
2. **React 19 + Three.js WebGL Architecture:** Running WebGL shaders alongside React 19 required clean unmounting cycles to avoid memory leaks.
3. **Micro-Interactions Elevate Brand Perception:** Dynamic circular wave buttons that expand from the cursor coordinates provide a tangible sense of luxury craftsmanship.
4. **Scarcity & Transparency Build Urgency:** Live empty leg savings percentages and flight counters transform passive browsers into active users.

## 🏃 Running the Project Locally

### Prerequisites
* **Node.js**: Version 18.18 or higher (Node 20+ recommended).
* **Package Manager**: `npm` or `pnpm`.
* **Git**: To clone the repository.

### Setup Instructions

```bash
# 1. Clone the repository
git clone https://github.com/hxrshrathore/aerolux.git
cd aerolux-concept

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env.local

# 4. Start local development server
npm run dev

# 5. Open in browser
# Visit http://localhost:3000
```

### Useful Scripts
* `npm run dev` — Starts Next.js development server with Turbopack.
* `npm run build` — Builds production-ready application.
* `npm run start` — Runs the compiled production build locally.
* `npm run lint` — Runs ESLint code quality checks.
